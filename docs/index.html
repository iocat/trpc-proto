Quickstart

From router to browser
in four moves.

Start with direct mode: the included Node server invokes your real tRPC resolvers in-process. No separate backend is required.

Follow the complete setup →
  1. 01

    Describe the contract

    Add protobuf metadata and an explicit output schema to each procedure.

    src/router.ts 
    const t = initTRPC.meta<ProtoMeta>().create({
  defaultMeta: {
    proto: {
      package: 'example.v1',
      schemaPath: 'generated/schema.ts',
    },
  },
});

export const appRouter = t.router({
  getUser: t.procedure
    .input(z.object({ id: z.string() }))
    .output(z.object({ id: z.string(), name: z.string() }))
    .query(({ input }) => ({ id: input.id, name: 'Ada' })),
});
  2. 02

    Generate the shared contract

    After installing @trpc-proto/plugin, run its local trpc-proto binary whenever your router changes.

    $ npx trpc-proto generate --router src/router.ts --export appRouter --out generated
    generated/ example_v1.proto schema.ts
  3. 03

    Serve the router

    Start the direct gRPC-Web server with the generated runtime schema.

    await serveGrpcWeb(appRouter, { schema: protoSchema, port: 50052 });
  4. 04

    Connect the browser

    Add grpcWebLink, then call procedures through the inferred AppRouter type.

    const client = createTRPCClient<AppRouter>({
      links: [grpcWebLink({ schema: protoSchema, url })],
    });
    const user = await client.getUser.query({ id: '1' });
